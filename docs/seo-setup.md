# Panduan Daftar Google Search Console

1. Buka https://search.google.com/search-console
2. Klik "Tambah Properti"
3. Masukkan URL domain: https://rambipuji.desa.id
4. Verifikasi kepemilikan dengan HTML tag atau DNS record
5. Setelah terverifikasi, klik "Sitemap" di menu kiri
6. Masukkan URL sitemap: https://rambipuji.desa.id/sitemap.xml
7. Klik "Kirim"
8. Google akan mulai mengindeks halaman dalam 1-4 minggu

Tips agar cepat diindeks:
- Minta Google crawl manual: "Pemeriksaan URL" → masukkan URL → "Minta Pengindeksan"
- Prioritaskan halaman: /tentang, /potensi, /peta
- Isi data potensi selengkap mungkin (deskripsi, foto, kontak)
